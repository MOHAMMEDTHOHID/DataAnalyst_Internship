#Data Analystics Internship-Apexplanet
For Task 1: 
Data Immersion & Wrangling, I focused on the foundational phase of the data lifecycle: acquiring, cleaning, and preparing a dataset for meaningful analysis. This stage is critical for ensuring that all subsequent insights are based on high-quality, reliable data.  
Task 1 Summary :
Data Familiarization: 
I gained access to a primary dataset—such as sales transactions or customer data—and created a comprehensive data dictionary to document the meaning, type, and business relevance of every variable.  
Quality Assessment: 
I performed initial data profiling to detect critical quality issues, including missing values, duplicates, inconsistent formatting, and outliers.  
Cleaning & Transformation:
Using Python (Pandas)  I wrote scripts to handle the identified issues. This included standardizing date formats, categorizing text fields, and performing feature engineering, such as deriving customer age from date-of-birth records.  
Final Output: 
The process resulted in a refined, analysis-ready dataset that serves as the basis for the upcoming Exploratory Data Analysis (EDA) tasks.
